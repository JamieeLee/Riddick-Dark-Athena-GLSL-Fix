# Changelog

## v1.0.0 — November 2026

- Added a ready-to-use `HLInclude_GLSL.xrg` replacement file for drag-and-drop installation.
- Replaced the `tex2DBias` and `texCubeBias` helper functions with macros while retaining their original texture-bias arguments.
- Kept an optional offline PowerShell patcher for modifying an untouched local shader file.
- Initial in-game validation: NVIDIA GeForce RTX 4070 SUPER. Wider compatibility and the script installer remain unverified.
